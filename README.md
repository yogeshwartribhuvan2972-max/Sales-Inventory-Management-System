# Sales & Inventory Management System

A Python-based project for managing products, stock, sales, revenue, and profit analysis.

## Features

* Add Product
* View Products
* Search Product
* Update Stock
* Delete Product
* Low Stock Alert
* Revenue Calculation
* Profit Calculation
* CSV File Storage

## Technologies Used

Python, CSV File Handling, List, Dictionary, Loops, Functions

## Learning Outcome

Improved business logic implementation and real-world Python problem-solving skills.
